qbacktest.

A fast, scriptable, reproducible backtesting engine for retail traders & quant hobbyists.

Download for Linux (free)

Single static binary. No cloud subscription. No lock-in.

⚡ Fast

Rust + Polars. Run a strategy over months of hourly data in seconds.

🔁 Reproducible

Deterministic, scriptable, CI-friendly. Same inputs, same results.

📊 Real metrics

Sharpe, Sortino, max drawdown, win rate, profit factor, volatility.

🧪 Walk-forward

Out-of-sample validation with train/test splits and consistency scoring.

📄 HTML reports

Self-contained, shareable report with charts — no notebook needed.

🔒 Yours

Open-source core. Your data stays on your machine.

Quick start

# DCA backtest on your OHLCV data
qbacktest run --input btc_1h.csv --strategy DCA \
  --dca-interval 24 --dca-amount 100 --capital 10000 \
  --output report.html

Input: timestamp,open,high,low,close,volume CSV or Parquet.
