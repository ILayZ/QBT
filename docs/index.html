About

QBT is a fast, scriptable, reproducible backtesting engine for retail traders and quant hobbyists. A single Rust CLI binary reads CSV or Parquet, runs a strategy (DCA, MomentumSMA, VolAdjustedDCA, or your own), computes standard risk-adjusted metrics (Sharpe, Sortino, max drawdown, profit factor), and outputs a self-contained HTML report — no cloud, no subscriptions, no Python environment. Data stays on your machine.
